Where I'm at, stated plainly

Including the parts I haven't done yet.

I graduated with a Bachelor of Science in Information Technology in 2026. Most of what I actually know came from team projects, not lectures — chiefly our seven-person capstone, BuildHub, a desktop app for ordering PC parts.

I'm a beginner-to-early-intermediate programmer. I can build complete working applications, and the fundamentals are solid.

Working on right now

  • Java fundamentals and cleaner OOP design
  • Data structures & algorithms
  • Git workflow and branch hygiene
  • Semantic HTML and responsive CSS
  • SQL, so my apps stop losing data
  • Rewriting old code to see if I can improve it
The longer version — what I have and haven't done

Our capstone taught me more than the syllabus did — how to read other people's code, agree on scope, and handle the parts of a project nobody hands you in a textbook. Alongside it I taught myself C# and Windows Forms by building a student records system, mostly to check whether my Java concepts would transfer to another language. They did.

To be straight about the gaps: I have not worked in a professional engineering team, not shipped software to real users, and not maintained a production codebase. I'd rather tell you that now than have it come up in an interview.

What I do have is the habit of finishing projects, asking questions early, and picking up whatever the next task requires.

BuildHub Academic · Team of 7

Java · Swing

My capstone — a desktop app for browsing and ordering PC parts. Customers register, verify their account, build a cart, and pay with change calculated live.

What I built 8
  • Account sign-up with OTP verification and password reset
  • Login screens for account, Gmail, and Facebook sign-in
  • Catalogue: monitors, keyboards, RAM, motherboards, GPUs, cases, prebuilt systems
  • Cart on a JTable with live quantity and price updates
  • Payment flow computing subtotal, total, and balance due
  • Receipt generation with a printable order summary
  • Profile, settings, and log-out screens
  • 24 Java classes across login, catalogue, cart, and checkout
Java Swing NetBeans 22 JDK 22

Group project — built with seven of us, not solo work. Documentation and certificates are published here. Credentials are hardcoded and nothing is persisted to a database.
